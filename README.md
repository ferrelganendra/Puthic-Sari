# Puthic Sari

Website ecommerce florist untuk Puthic Sari, toko buket bunga di Yogyakarta.

## Fitur

- Katalog produk dan kategori buket
- Detail produk, wishlist, dan keranjang belanja
- Checkout dengan estimasi ongkir
- Pembayaran online melalui payment gateway
- Dashboard admin untuk mengelola produk, banner, pesanan, dan review
- Estimasi ongkir dan pengiriman melalui shipping provider

## Tech Stack

- React
- Vite
- Tailwind CSS
- Supabase

## Menjalankan Project

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Environment Variables

Daftar environment variables tersedia di `.env.example`.
